# 约五分钟演示脚本

本脚本用于作品展示。客户、企业、产品与资料全部为模拟，离线演示不调用模型。

## 0:00–0:40 说明任务

“售前需要把客户需求与真实可交付能力核对。本项目把需求、来源、结论、审核和交接放在一个流程里。第一版针对一款模拟协同办公产品。”

## 0:40–1:40 核验客户问卷

售前身份，离线演示，选择西岭科技问卷并开始核验。展示7项结果：企业微信和Excel已支持；LDAP和离线客户端不支持；路线图、两秒指标和香港数据驻留待确认。

“没有资料时系统保留待确认，不把客户提出的指标写成我方承诺。路线图也不是已上线功能。”

## 1:40–2:40 展示证据与差异

查看香港要求，展示两份当前已审核资料互相矛盾。查看LDAP，说明旧版支持不能覆盖当前版本。查看Excel，未审核销售笔记不能扩大能力范围。

可另创建澜舟集团私有部署问卷：企业微信云版支持，但私有版明确不支持。切换目标部署方式会改变依据。

## 2:40–3:40 人工审核

切换审核负责人，逐条检查答复。可将一项退回补充，其余批准。勾选确认并保存。导出已批准答复，解释待确认能力状态仍保留。

如演示改写，给待确认项写“支持，保证两秒”并保存，会被拦截；随后恢复原草稿再审核。

## 3:40–4:20 工单与恢复

选择已批准但不支持的离线客户端要求，创建测试工单；重复点击返回同一ID。在工单页展示来源任务。说明任务与人工审核通过SQLite及LangGraph检查点保存。

## 4:20–5:00 说明技术与结果

LangChain提供检索、处理链和工具接口；LangGraph负责暂停恢复；Pydantic约束结构。打开评测页，说明26个固定合成开发案例结果，以及这些结果不代表真实模型或企业收益。

“下一步是目标用户试用与真实资料评测，再决定语义检索和企业系统接入。现阶段可以证明流程和规则，尚不能证明真实用户效率提升。”
