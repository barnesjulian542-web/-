# 求职项目表述

项目名：有据 · 售前需求核验与答复工作台。

一句话：设计并实现面向B2B SaaS售前的证据核验原型，将客户要求、版本与部署适用性、人工审核及能力缺口交接串成可追溯流程。

可以使用的项目描述：

- 从售前需求核验任务出发，定义已支持、明确不支持和待确认三类结果，设计路线图、资料冲突、版本变化及无依据指标的处理规则。
- 基于LangChain、LangGraph、Pydantic和Streamlit完成本地工作台，支持模拟资料检索、审核暂停恢复、批准答复导出和幂等测试工单。
- 构建18份模拟产品资料、3份客户问卷和26个固定合成开发案例，保存完整评测结果并公开模型调用、规则范围与验证限制。

应依据 docs/VALIDATION.md 填写测试数与实测结果；不能改写为真实企业上线、访谈完成、独立测试集准确率、成交率提高或用户效率提升。

面试可展开的判断：为什么无证据要保留待确认；为什么查询权限在检索之前执行；为什么旧答案相似不能证明当前支持；为什么审核是一种业务决策，不能等同模型输出；为什么先验证工作流而没有引入多Agent。
