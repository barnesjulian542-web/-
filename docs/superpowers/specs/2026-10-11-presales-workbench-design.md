# 有据 · 售前需求核验与答复工作台

用途：AI 产品经理求职作品。用户已授权完成项目，并允许生成全部模拟资料；在本目录内设计、实现和验证。业务范围采用此前讨论的一款 SaaS、一类需求清单、人工审核和测试工单。

## 用户和任务

虚构产品为“云桥协同”，产品版本 3.2。售前录入客户需求，指定云端或私有部署与产品版本；系统检索有权访问的资料，核验能力，形成带原文依据的答复草稿。审核人逐条修改、批准或退回。批准后的答复可导出；能力缺口经审核后可建立本地模拟工单。

## 范围与行为

- 三个结论：已支持、明确不支持、待确认。无资料、路线图、当前资料矛盾和未知参数均为待确认。
- 已审核的当前产品资料可以支持结论；已过期或未审核的历史销售答复不能单独确立能力。
- 每条依据保存文档 ID、标题、版本、摘录和有效性；文档冲突展示原文，不自动掩盖。
- 需求原文保留；任何生成阈值、上线日期、认证、性能承诺均不得无依据成为答复。
- 查询先按资料角色权限筛选；销售只能访问销售资料，审核角色可访问内部资料。此为本地角色模拟，非生产登录认证。
- 默认离线演示：LangChain 检索组件与业务规则实际执行，不调用大模型，不声称为模型效果。真实模型模式需要本项目单独配置，使用 LangChain 模型接口；失败显式报错，不伪装成成功结果。
- 默认检索为透明的中文词项/二元字符检索，不称为语义向量检索。保留以后替换检索器的模块边界。
- LangGraph SQLite 检查点用于人工审核暂停、重启恢复；应用 SQLite 保存任务、结果、审核和事件。
- 审核前不可导出为已批准答复；未知/冲突内容不得被审核动作升级为已支持。人工可调整文字，但承诺性新增信息须回到资料核验。
- 工单只在本地测试库建立，通过数据库唯一约束避免重复；所有审阅与执行均记录事件。
- 数据全部为明确标注的模拟数据；不接触原反馈工作台配置、虚拟环境和数据库。

## 页面

原生 Streamlit，中文、浅色、青绿色主题。侧边导航包括工作台、证据库、测试工单、评测与项目说明。工作台有任务概览、客户需求表单、任务列表、结果详情、逐条审核、导出及执行轨迹。提供三个预设客户问卷，也接受逐行文字与 UTF-8 CSV（requirement 列）。证据库可搜索并查看完整资料；评测页明确说明合成数据、规则模式与未进行真实用户验证。

## 模块

- `presales/models.py`：Pydantic 输入、需求、引用、核验及审核契约。
- `presales/catalog.py`：载入生成的文档与能力元数据。
- `presales/retrieval.py`：LangChain BaseRetriever，有权限/版本标注的词项检索。
- `presales/analyzer.py`：离线解析、真实模型抽取、证据决策、生成与检查。
- `presales/storage.py`：SQLite 任务/审核/工单/事件及幂等事务。
- `presales/workflow.py`：LangGraph extract→verify→human review→finalize。
- `presales/service.py`：页面与命令共用入口，恢复与执行边界。
- `presales/exports.py`：批准答复与草稿导出，CSV 公式字符处理。
- `app.py`：界面；`scripts/generate_data.py`：模拟资料；`scripts/evaluate.py`：冻结案例评测。

## 验证与交付

先编写关键失败测试，再实现规则、权限和持久化；使用真实临时 SQLite 验证恢复、审批门槛与重复执行。AppTest 验证表单、审核和导航。评测使用独立于产品文档的固定预期，保留失败输出；不能把自动通过写作真实用户准确率。提供运行说明、PRD、演示脚本、评测报告和当前限制。
